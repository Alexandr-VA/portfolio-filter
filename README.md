# Portfolio-filter

Веб-приложение портфолио проектов с фильтрацией по категориям.

## Технологии

- React (классовый компонент `Portfolio`, функциональные `Toolbar` и `ProjectList`)
- CSS Grid

## Запуск

\`\`\`bash
npm install
npm start
\`\`\`

Приложение откроется на http://localhost:3000

## Архитектура

- `Portfolio` — хранит состояние (активный фильтр, список проектов), фильтрует данные.
- `Toolbar` — отображает кнопки-фильтры, вызывает `onSelectFilter`.
- `ProjectList` — отображает переданный список проектов.

## Функциональность

- Фильтрация проектов по категориям: All, Websites, Flayers, Business Cards.
- Активный фильтр визуально выделен.
